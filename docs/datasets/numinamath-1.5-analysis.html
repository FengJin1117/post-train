数据集说明 官方数据集卡描述其为约 90 万条竞赛级数学题的高质量 post-training 数据，每条解答以 Chain-of-Thought 形式组织，来源覆盖中国高中数学练习、美国及国际数学奥赛题、线上试卷 PDF 与数学论坛。
简要判断：适合作为数学后训练候选集，但不建议不加过滤地全量直接 SFT。推荐先用 problem_is_valid=Yes 且 solution_is_valid=Yes 的 819,033 条作为主池，再按任务选择 word-problem、proof、MCQ 和来源配比。

质量风险

主要风险：数据量足够大，但存在答案不可验证、解答不完整、图片依赖、合成数据占比较高和潜在 benchmark 污染等问题。训练前需要过滤和分层采样。

训练适配建议

目标方法 适配性 建议用法
LoRA-SFT / Full SFT 适合，需过滤 用 problem + solution 构造成 messages，优先取 738,822 条非图片、非 notfound、有答案和 solution 的样本；控制合成数据比例，避免覆盖基模已有通用能力。
GRPO / DAPO 很适合 主用 549,673 条可验证 word problem，保留 solution 和 answer 作为 reward/reference 信息；配合 accuracy 与 format reward。
DPO 需要额外构造 原数据没有 rejected response，不能直接作为 DPO 数据集；可从模型采样错误解构造 preference pairs。
PPO 可做 prompt 池 可使用 prompt-only 题目池，但 reward 需要另行定义；可验证答案题优先。
Agent 不是首选 数据不含工具调用轨迹，除非改造成解题工具调用或代码执行环境，否则对 Agent benchmark 帮助有限。

Benchmark 相关性

  • GSM8K：orca_math、synthetic_math 和基础 word problem 很相关，预计能提升格式稳定性与中低难算术题表现；当前基线 84.69 已不低，需防止过训造成退化。
  • MATH-500：olympiads、aops_forum、number_theory、inequalities 更相关，建议提高竞赛来源采样权重。
  • GAOKAO：cn_k12 和 cn_contest 有明显相关性，但数据文本主要是英文；若评测题为中文，仍需补充中文题面或中文 SFT 数据。
  • AIME25：amc_aime 仅 5,872 条，直接提升可能有限；建议作为高权重小池，配合 olympiad/AoPS 难题训练，并做污染检查。

推荐首轮训练池

建议首轮不要直接吃全量 896,215 条，而是构建两个子集：

  • SFT 子集：从 738,822 条非图片、非 notfound、有答案和有效 solution 的样本中采样，限制 synthetic=true 比例，按 benchmark 目标提高 olympiads、aops_forum、cn_contest、amc_aime 权重。
  • GRPO/DAPO 子集：优先使用 549,673 条可验证 word problem；训练前检查答案抽取格式，让 reward 可以稳定识别整数、分数、选项和 LaTeX 表达式。

最终结论

结论：AI-MO/NuminaMath-1.5 适合作为 Qwen2.5-3B-Instruct 数学后训练的数据集候选，并且更适合作为经过过滤和分层采样后的训练池，而不是原样全量训练集。

它的优势是规模大、覆盖广、已有答案和题型元数据、ms-swift 已注册，能直接服务 SFT 与 GRPO/DAPO。对 GSM8K 和 MATH-500 的相关性最明确；对 GAOKAO 和 AIME25 也有价值，但需要更细的语言、难度和污染控制。

执行上，首轮建议用过滤后的 SFT 子集建立解题格式，再用可验证答案子集做 GRPO/DAPO。若目标是 AIME25，必须额外提高高难竞赛题权重，并避免低难合成题占比过高。
