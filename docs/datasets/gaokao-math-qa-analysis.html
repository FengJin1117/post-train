定位与结论

适合作为 4k 数学推理选择题 benchmark。共 351 道四选一/多选题，输入很短，可用选项集合准确率自动评分。它与 GaoKao Math Cloze 必须独立报告。

标准数据采用 AGIEval v1.1 的 gaokao-mathqa。Qwen2.5-Math 中的 gaokao_math_qa 题目与标签对应一致，仅将选项从列表规范化为字典。

关键风险：数据中有 7 道多选题。默认“取最后一个选项字母”的单选评分会错误评估这些题；应将模型答案规范化为 A–D 集合并做完全匹配。

单选标签分布较均衡：A 85、B 87、C 92、D 80。多选标签包括 AC、AD、ACD、ABD、BCD、CD；随机单选基线约为 25%，但无法正确覆盖多选题。

不要直接使用只支持单选的 general_mcq 默认评分器，除非先扩展为多选集合评分。标准主指标应为 351 题逐题 exact-set accuracy，每题等权。

数据质量与报告规范

  • 标准集：351 题；存在 3 条重复行，标准可比结果仍报告 351 题准确率。
  • 建议附加报告去重后的 348 题准确率，但不要替代标准分数。
  • 未发现明确依赖缺失图片的题目；出现“图象/图像”的题目均有文本数学定义。
  • 主指标：exact-set accuracy。多选题少选、多选或错选均计 0 分。
