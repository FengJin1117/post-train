# Qwen2.5-3B Base Clean-10K 双配方 LoRA-SFT

## 目标

使用统一 ChatML 评测协议，判断 clean-10K 是否能为 raw Qwen2.5-3B
建立数学指令能力。

## 配方

| Run | GPUs | LR | LoRA | Epochs |
| --- | --- | ---: | --- | ---: |
| B1 | 0,1,4 | 1e-5 | rank 8, attention projections | 1 |
| B2 | 5,6,7 | 5e-5 | rank 16, all-linear | 2 |

训练前先完成 raw base 的完整 GSM8K/MATH-500 与固定子集门禁评测。
B1/B2 都从原始 base 模型开始，完成两步 smoke 后并行正式训练。

门禁要求相对 raw base 固定子集在 GSM8K 和 MATH-500 上均提升至少
5 个百分点，并满足 boxed、截断与重复输出稳定性约束。
